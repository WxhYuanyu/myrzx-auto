# 每日委托

三条已经走完的委托共用同一组动词，各自只保留一份短配方。未收录的中间页会先跳过。任何阶段都不点「扫荡」。

画面标题 **喳喳布林入侵** 按原文匹配。

类型3「“热情”的冒险者」是多场战斗：图兰顿沙漠地区 9-7-1 打三场正式战斗。事件弹窗不计数。

## 共用动词

| 动词 | 做什么 | 不做什么 |
| --- | --- | --- |
| 打开委托 | 协会右下「委托」 | 不在列表已经打开时再点一次 |
| 接卡片 | 只点配方里的那张标题 | 找不到就停，不改点别的卡 |
| 接收 | 任务详情右下「接收」 | |
| 返回 | 卡片右上箭头，并等关窗动画 | 不点屏幕底部「离开」 |
| 离开 | 协会室内，或阿格莱恩地图左下 | 先看左上角地名，克里斯汀上不点这个离开去别处 |
| 点脸 | NPC 头像模板的中心 | 模板不含三点气泡 |
| 跳过剧情 | 右上「跳过剧情」 | |
| 打开卷轴 | 右上出现绿勾后点卷轴本体 | 不点邮件、背包 |
| 点标题 | 日志里该委托的标题行 | 不点绿色「完成」印章 |
| 完成 | 详情中下部米色按钮，约 y=1310 | 不是屏幕最底部 |
| 领奖 | 「获得物品」上的「触摸继续」 | |

## 类型1：喳喳布林入侵（战斗）

接取后进入 1-3，与小孩对话并跳过剧情，等待自动战斗，再从任务日志领取奖励。

## 页面流程

```
WORLD_MAP（阿格莱恩大地图）
    依据：左上蓝色横幅「阿格莱恩」
    动作：若看不见「王城莉莉托斯」（例如停在南赛拉姆），先向下滑动地图露出北边王城，再点击金色标签「王城莉莉托斯」
        │
        ▼
CITY_LILITOS（王城内节点图）
    接取前：点击金色标签「协会」
    接取后：点击右下底栏「探险」（不要点「探索」）
        │
        ▼
ASSOCIATION（协会室内）
    接取前：点击右下角木牌按钮「委托」（带感叹号角标）
    接取后：点击左下「离开」，返回城内再去「探险」
        │
        ▼
COMMISSION_LIST（驯养师协会委托中心）
    依据：顶部标题「驯养师协会委托中心」
    接取前：点击卡片标题「喳喳布林入侵」
    接取后：用卡片右上返回箭头关闭列表，等关窗动画后再点协会「离开」
        │
        ▼
QUEST_DETAIL（任务详情，尚未接受）
    依据：左上「任务详情」；状态为「尚未接受任务」
    动作：点击「接收」
    接取后：弹出「接取了委托任务 喳喳布林入侵」，目标变为
            「消灭 莉莉托斯郊外 1-3 的入侵的喳喳布林」，「接收」消失。
            用卡片右上返回箭头关闭详情（不要立刻点屏幕底部「离开」，动画未结束会被吃掉）。
        │
        ▼
CITY_LILITOS（再次）
    动作：点击右下「探险」
        │
        ▼
STAGE_MAP（关卡选择图，1-1…1-4 与甜蜜幻窟）
    依据：「甜蜜幻窟」等
    动作：点击带「1-3」字样的旗帜（模板必须含关卡编号，避免误点 1-2 / 1-4）。
          接取后 1-3 旁可能有对话气泡，但点击目标仍是旗帜本身。
        │
        ▼
STAGE_1_3（莉莉托斯近郊 1-3，战前）
    动作：点击左下角小孩头像（约 90,1460），不要点边缘的三点气泡。
          不要先点「进入」或「扫荡」。
        │
        ▼
STORY_DIALOG（剧情对话）
    动作：点击右上角「跳过剧情 >>」。跳过战前对话会直接进入战斗，无需再点「进入」。
        │
        ▼
BATTLE（战斗中）
    依据：左下「活力点」等战斗 HUD。标题可能为「入侵的喳喳布林」。
    动作：不要点击。自动战斗开启，只轮询截图，直到胜利结算。时限约数分钟。
          若中途再出现剧情，仍点「跳过剧情」。
        │
        ▼
VICTORY（战斗胜利）
    依据：大字「战斗胜利」和「触摸继续」
    动作：点击「触摸继续」，或点屏幕中部（约 540,1100）。
        │
        ▼
STORY_DIALOG（战后剧情，若出现）
    动作：再次点击右上「跳过剧情」
        │
        ▼
STAGE_1_3（战后）
    说明：小孩已消失；右上任务卷轴出现绿色完成勾。
    动作：点击卷轴本体（约 847,216），不要点邮件或背包。
        │
        ▼
QUEST_LOG（任务日志，剧情页）
    依据：左上「任务」
    动作：先点击该委托的标题行「喳喳布林入侵」打开详情。
          列表上的绿色「完成」印章不是领取按钮，不要点它。
        │
        ▼
QUEST_DETAIL（已完成的任务详情）
    动作：点击详情中下部、奖励图标下方的米色「完成」按钮（中心约 910,1310）。
          不要点屏幕最底部（y≈1800 会点空），也不要点返回箭头。
        │
        ▼
LOOT_REWARD（获得物品）
    依据：标题「获得物品」与「触摸继续」（例如 20 氚金、400 金币、经验等）
    动作：点击「触摸继续」。之后任务从日志中消失，本条委托结束。
```

每日可接数量上限为 6，列表在午夜刷新。接取前示例为 4/6，接取后该卡从板面消失，可接数量变为 3/6。

## 优先委托

画面上的标题是 **喳喳布林入侵**。本工具按屏幕原文匹配。

已知信息：

- 地点：王城莉莉托斯协会委托

## 类型3：「“热情”的冒险者」（多场战斗）

实走帧在 `tests/fixtures/multi_battle/`（1080×1920）。同一张胜利图和选关图在文件夹里重复了几次，这样按文件名跑一遍干跑就能把正式战斗数到 3。这是图兰顿沙漠协会的紫色紧急委托。详情文案是「快来跟我比赛挑战怪物吧！」。接取后目标是「击杀30只萨克毒蝎后与图兰顿要塞的冒险者对话」。奖励可见为 900 金币、经验 20、紫水晶 20，以及红碎片和地图碎片。

只打 **9-7** 的 **初步探索**（9-7-1），正式战斗打满 3 次。特殊事件关掉后重新进入，不加次数。
