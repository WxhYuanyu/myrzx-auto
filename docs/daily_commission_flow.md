# 每日委托：喳喳布林入侵（已知完整路径）

当前实现覆盖实走记录的全程：接取「喳喳布林入侵」，进入 1-3 与小孩对话并跳过剧情，等待自动战斗，再从任务日志领取奖励。

未收录的中间页会先跳过，等到能识别的画面再继续。任何阶段都不会点「扫荡」。

## 页面流程

```
WORLD_MAP（阿格莱恩大地图）
    依据：左上蓝色横幅「阿格莱恩」
    动作：若看不见「王城莉莉托斯」（例如停在南赛拉姆），先向下滑动地图露出北边王城，再点击金色标签「王城莉莉托斯」
        │
        ▼
CITY_LILITOS（王城内节点图）
    接取前：点击金色标签「协会」
    接取后：点击右下底栏「探险」（不要点「探索」）
        │
        ▼
ASSOCIATION（协会室内）
    接取前：点击右下角木牌按钮「委托」（带感叹号角标）
    接取后：点击左下「离开」，返回城内再去「探险」
        │
        ▼
COMMISSION_LIST（驯养师协会委托中心）
    依据：顶部标题「驯养师协会委托中心」
    接取前：点击卡片标题「喳喳布林入侵」
    接取后：用卡片右上返回箭头关闭列表，等关窗动画后再点协会「离开」
        │
        ▼
QUEST_DETAIL（任务详情，尚未接受）
    依据：左上「任务详情」；状态为「尚未接受任务」
    动作：点击「接收」
    接取后：弹出「接取了委托任务 喳喳布林入侵」，目标变为
            「消灭 莉莉托斯郊外 1-3 的入侵的喳喳布林」，「接收」消失。
            用卡片右上返回箭头关闭详情（不要立刻点屏幕底部「离开」，动画未结束会被吃掉）。
        │
        ▼
CITY_LILITOS（再次）
    动作：点击右下「探险」
        │
        ▼
STAGE_MAP（关卡选择图，1-1…1-4 与甜蜜幻窟）
    依据：「甜蜜幻窟」等
    动作：点击带「1-3」字样的旗帜（模板必须含关卡编号，避免误点 1-2 / 1-4）。
          接取后 1-3 旁可能有对话气泡，但点击目标仍是旗帜本身。
        │
        ▼
STAGE_1_3（莉莉托斯近郊 1-3，战前）
    动作：点击左下角小孩头像（约 90,1460），不要点边缘的三点气泡。
          不要先点「进入」或「扫荡」。
        │
        ▼
STORY_DIALOG（剧情对话）
    动作：点击右上角「跳过剧情 >>」。跳过战前对话会直接进入战斗，无需再点「进入」。
        │
        ▼
BATTLE（战斗中）
    依据：左下「活力点」等战斗 HUD。标题可能为「入侵的喳喳布林」。
    动作：不要点击。自动战斗开启，只轮询截图，直到胜利结算。时限约数分钟。
          若中途再出现剧情，仍点「跳过剧情」。
        │
        ▼
VICTORY（战斗胜利）
    依据：大字「战斗胜利」和「触摸继续」
    动作：点击「触摸继续」，或点屏幕中部（约 540,1100）。
        │
        ▼
STORY_DIALOG（战后剧情，若出现）
    动作：再次点击右上「跳过剧情」
        │
        ▼
STAGE_1_3（战后）
    说明：小孩已消失；右上任务卷轴出现绿色完成勾。
    动作：点击卷轴本体（约 847,216），不要点邮件或背包。
        │
        ▼
QUEST_LOG（任务日志，剧情页）
    依据：左上「任务」
    动作：先点击该委托的标题行「喳喳布林入侵」打开详情。
          列表上的绿色「完成」印章不是领取按钮，不要点它。
        │
        ▼
QUEST_DETAIL（已完成的任务详情）
    动作：点击详情中下部、奖励图标下方的米色「完成」按钮（中心约 910,1310）。
          不要点屏幕最底部（y≈1800 会点空），也不要点返回箭头。
        │
        ▼
LOOT_REWARD（获得物品）
    依据：标题「获得物品」与「触摸继续」（例如 20 氚金、400 金币、经验等）
    动作：点击「触摸继续」。之后任务从日志中消失，本条委托结束。
```

每日可接数量上限为 6，列表在午夜刷新。接取前示例为 4/6，接取后该卡从板面消失，可接数量变为 3/6。

## 优先委托

画面上的标题是 **喳喳布林入侵**（用户也这样写）。不要写成「嗥嗥」或「嗫嗫」。本工具按屏幕原文匹配。

已知信息：

- 地点：王城莉莉托斯协会委托
- 要求：通关 1-3；部分委托需要先和 NPC 对话，本条是左下角的小孩
- 奖励：400 金币 + 20 氚金等（以「获得物品」弹窗为准）

## 仍需用户提供的信息

1. **模拟器窗口（MuMu）精确标题和类名**  
   已把默认查找设为 MuMu，并兼容 12 / 旧版 / 5.0 的标题与渲染子窗口。
   请在运行游戏的 Windows 上执行 `python main.py --list-windows`，把顶层窗口和
   `MuMuPlayer` / `NemuPlayer` / `MuMuNxDevice` 子窗口那几行发回来，以便锁定精确匹配。
   `--live` 的完整点击循环仍要等这项确认后再接上。

其他委托如果目标关卡或 NPC 不同，需要另行补充截图，不会套用本条小孩对话流程去点别的委托。
